Проектирование серверной логике
Логика создания тестов и тестирований 
Создается вопрос с определенным типом ответа.

Если тип вопроса “ввод значения”, “выбор варианта”, “выбор нескольких вариантов ответа” данные записываются в “AnswerOptions”.
Если тип вопроса “сопоставление” данные записываются в “MatchigItem”
Если тип вопроса “установление последовательностей” данные записываются в “OrderingItem” 
Если тип вопроса “параметризованная задача” данные записываются в “ParameterizedTask” 
Объединение теста с вопросами.(тест создан)

Объединение тестирования с тестами.(тестирование создано)

Публикация тестирования
	У тестирования есть три состояния - проект, опубликовано, архивировано.  Соответственно при статусе опубликовано тестирование можно пройти участникам.
	На тестирование может записать как и сам участник, так и его может назначить администратор.
	В таблице “TestAssigments” показывается все записи на тестирования, и там же есть информация какой тест сейчас проходит участник
	
Проверка и сохранение ответов
	Результаты теста хранятся в таблице “ResultTest”
	
А результаты на конкретные вопросы хранятся в таблице “UserAnswers”

Сами же ответы хранятся в отдельных таблицах в зависимости от типа вопроса
